Step 3

Install it

Classic Outlook for Windows

Outlook cannot load a signature from a web address. You paste the rendered signature instead, which keeps the table, colours and logo.

  1. Set Logo images to Hosted and check the folder URL, then click Copy signature.
  2. In Outlook: File → Options → Mail → Signatures…
  3. Click New, name it (for example Fearless), click into the big editing box and press Ctrl+V.
  4. Under Choose default signature, set it for New messages and Replies/forwards, then OK.
If the logo shows as a red X after pasting, Outlook could not reach the image URL. Fix the folder URL, or switch to Embedded and paste again. Pasting from Edge or Chrome works best.

New Outlook and Outlook on the web

Same idea: paste the rendered signature. These versions store the signature in your Microsoft 365 mailbox, so it follows you to any computer.

  1. Set Logo images to Hosted, then click Copy signature.
  2. Click the gear icon → Accounts → Signatures (on the web: Settings → Mail → Compose and reply).
  3. Click New signature, give it a name, click into the editor and press Ctrl+V.
  4. Pick it as the default for new messages and for replies, then Save.

Outlook for Mac

  1. Set Logo images to Hosted (or Embedded, both work on Mac), then click Copy signature.
  2. Outlook → Settings → Signatures, click +.
  3. Click into the signature body and press ⌘+V. Name it and close the window.
  4. At the bottom of the Signatures pane, choose it as the default for your account.

Thunderbird

Thunderbird can read the signature straight from a file, which is the easiest route of all.

  1. Set Logo images to Embedded, then click Download .html (or Copy HTML source and save it as signature.html).
  2. Account Settings → pick your account.
  3. Tick Attach the signature from a file instead, click Choose… and select the file.
  4. Thunderbird embeds the logo in each message as an inline image, so recipients see it without loading remote content.
Prefer pasting? Tick Use HTML on the account page and paste the HTML source (not the rendered signature) into the signature box.

Gmail

  1. Set Logo images to Hosted. Gmail strips embedded images.
  2. Click Copy signature.
  3. In Gmail: gear → See all settings → General → Signature → Create new.
  4. Click into the editor, press Ctrl+V, set the signature defaults below it and Save Changes at the bottom.

Roll it out to the whole company

If OGF's mail runs on Microsoft 365, an administrator can attach a signature server-side so nobody has to install anything, and it works on phones too.

  1. The PNGs are already hosted at https://rsty-shackleford.github.io/ogf-signature/img/.
  2. In the Exchange admin center: Mail flow → Rules → Add a rule → Apply disclaimers, condition: sender is a member of the division's group.
  3. Paste the division template from the templates folder and swap the placeholders for Exchange attributes: %%DisplayName%%, %%Title%%, %%MobilePhone%%, %%PhoneNumber%%, %%Email%%.
  4. Fill in each person's title and phone numbers in their Microsoft 365 profile. The rule reads them from there.
A transport rule adds the signature at the very bottom of the message, below any quoted replies. Third-party tools such as Exclaimer or CodeTwo place it under the newest reply instead, if that matters to you.
Why it hangs together

One palette, three marks

OGF and Fearless are black wordmarks, so black carries the name and the fine print. The steel blue was chosen to sit beside the Crossroads navy, and it is the only accent OGF and Fearless use. Orange is reserved for Crossroads. Every signature uses the same type, spacing and grey, so the three read as one family side by side.
