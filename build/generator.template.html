Classic Outlook for Windows

Classic Outlook has a File menu in the top-left corner. No File menu? Use the New Outlook & web tab instead.

  1. Click Copy signature above.
  2. In Outlook, click File → Options → Mail → Signatures…
  3. Click New, type a name (for example Work) and click OK.
  4. Click inside the large Edit signature box and press Ctrl+V.
  5. On the right, under Choose default signature, pick your new signature for both New messages and Replies/forwards.
  6. Click OK, then start a new email to check it.

New Outlook and Outlook on the web

This is the Outlook with a New Outlook switch at the top right, and Outlook in a web browser.

  1. Click Copy signature above.
  2. In Outlook, click the gear icon (Settings) at the top right.
  3. Go to Accounts → Signatures.
  4. Click New signature, type a name, click inside the editor box and press Ctrl+V.
  5. Under Select default signatures, pick it for both New messages and Replies/forwards.
  6. Click Save, then start a new email to check it.

Outlook for Mac

  1. Click Copy signature above.
  2. In Outlook, click the Outlook menu → Settings → Signatures.
  3. Click +, type a name, click inside the signature box and press ⌘+V. Close the editor window.
  4. Under Choose default signature, pick it for both New messages and Replies/forwards.

Gmail

Leave Logo images (Step 2) on Hosted. Gmail does not accept embedded logos.

  1. Click Copy signature above.
  2. In Gmail, click the gear icon → See all settings.
  3. On the General tab, scroll down to Signature and click Create new. Type a name and click Create.
  4. Click inside the signature box and press Ctrl+V.
  5. Under Signature defaults, pick it for For new emails use and On reply/forward use.
  6. Scroll to the bottom and click Save Changes.

Thunderbird

Thunderbird reads the signature from a file instead of a paste.

  1. Under Logo images (Step 2), choose Embedded.
  2. Click Download .html above and save the file somewhere you will not delete it.
  3. In Thunderbird, open the ≡ menu → Account Settings and click your email address on the left.
  4. Tick Attach the signature from a file instead, click Choose… and pick the file you saved.
No Download button? Click Copy HTML source, paste it into Notepad and save it as signature.html.

For the IT admin: add it to everyone's mail server-side

On Microsoft 365, an admin can attach the signature to every outgoing message with an Exchange mail-flow rule. Nobody installs anything, phones are covered, and the logos switch to white in dark mode. Full details are in the README on GitHub.

  1. Open the division's file in templates/exchange/. It already uses %%DisplayName%%, %%Title%%, %%MobilePhone%% and %%Email%%.
  2. Exchange admin center: Mail flow → Rules → Add a rule → Apply disclaimers. Condition: sender is a member of the division's group. Action: append; paste the file's contents. Fallback: Wrap.
  3. Fill in each person's Title and Mobile phone on their Microsoft 365 profile.
  4. Send a test to an outside account and read it in Outlook on the web with dark mode on.
